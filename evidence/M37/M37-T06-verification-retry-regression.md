# M37-T06 复核失败重试验收

日期：2026-10-20。完整接口与恢复语义见 `docs/project-verification-provider.md`。

## 已实现

- operationId + 前驱 attemptId 显式重试；请求重放/冲突/并发互斥；最多 3 次调用。
- 调用前 PostgreSQL 原子预留并提交；事务外出站；独立事务记录结果和历史。
- 确定性拒绝不调用、不占额；未知结果保留预留、不盲目重放；重启后安全查询。
- attemptId 传递至供应商关联头；内部额度不冒充外部实际账单。
- 独立原图/缩略图鉴权读取；元数据无 base64；后台重试和 UNKNOWN 展示。

## 测试证据

- 服务端相关组合 92 项通过（新增 reset 护栏/调用关联头前的完整回归）。
- 最终复核单元/API、远程 PostgreSQL、迁移及 Harness 结果记录于 Harness 完成记录。
- 真实 PostgreSQL 用随机隔离 schema，覆盖调用前可见预留、临时失败后成功、
  跨实例重放/并发、额度边界、模拟进程中断、连接重开和未知状态持久化。
- 后台 18 个测试文件共 119 项通过；类型检查与生产构建通过。
