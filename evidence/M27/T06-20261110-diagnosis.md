# M27-T06 安全帽移动模型本地 / 生产产物差异诊断

日期：2026-11-10（Asia/Shanghai）。交付类型：**本地隔离诊断与回归，不是生产修复 / 发布 / 精度验收**。

## 结论

1. 用户提供的异常 TFLite 在电脑上可稳定复现低分；不依赖当前手机连接哪个服务。正常本地产物在同图、同输入张量、同阈值下正常出候选。
2. 已在本地确认具体缺陷机制：`litert-torch 0.9.3` 常量 lowering 的缓存键包含内存地址 / shape / stride / offset，但未保留生成该地址的临时连续张量。临时张量释放后地址复用，使不同卷积权重命中同一个缓存键。
3. 在本地 `Ultralytics 8.4.138 + torch 2.12.1+cpu` 组合抓到 **17 次同键不同内容**；转换前 eager 模型正常，而尚未 INT8 量化的 FP32 TFLite 已失真。保持临时常量张量存活后，碰撞降为 **0**。两次隔离干预的 INT8 模型图均与正常本地产物**逐字节一致**，同图原始输出亦逐字节一致。这不是通过降低阈值获得的结果。
4. 用户提供的异常产物与正常产物共有 81 个 CONV_2D。17 层权重不一致，其中 **14 层的权重字节及量化参数匹配另一层**，与本地复现的错误机制高度吻合。余下 3 层没有在正常模型中找到相同权重，不对其来源强行推断。
5. 因未读取生产进程、实际输入 PT bytes、完整依赖和转换日志，不能声称已直接观察生产执行时的内存碰撞；也未复现异常文件的完整 hash。准确表述是：**本地根因机制已复现并经干预验证；生产来源异常文件存在同类权重串用证据，生产运行链路尚待核验。**

## 控制变量实验与根因证据

所有导出均在 `evidence/M27/` 全新目录，以同一源 PT 的副本生成候选；未使用服务 worker、未安装/升级共享环境、未覆盖旧模型或 registry。新版纯 Python package 从现有 Windows 安装复制到隔离目录，在同一 WSL Python 中导入；版本依据 `ultralytics.__version__` 和全包 `.py` hash，不误用共享环境的 distribution metadata。

共用底层版本：torch 2.12.1+cpu、litert-torch 0.9.3、ai-edge-litert 2.1.6、ai-edge-quantizer 0.8.0、litert-converter 0.3.1、numpy 2.5.2、Pillow 12.3.0。每次 torch seed=0，CPU单线程，export参数为 format=litert、imgsz=640、quantize=int8、nms=False、batch=1、device=cpu。先零图predict，匹配当前worker路径。

错误路径：`litert_torch/backend/inline_consts.py` 中 `tensor_lowering_placeholder_lowering` 执行 `x.contiguous().detach().cpu()` → `_ConstantFingerprint.from_tensor(x)` → 以该 key 取/存 `constant_cache`。键字段为 device、shape、stride、storage pointer、storage offset；缓存只保留 MLIR attribute，未保留临时连续 storage。记录到相同键先后对应不同 SHA256，导出权重随之误用。

诊断干预只在当前实验进程中将 fingerprint 处理到的张量放入列表保活到导出结束，共178个；不修改共享库源码。这是机制验证，不是直接可发布的产品补丁；产品化还需考虑生命周期、并发、内存、版本兼容与完整回归。

## 校准集与其他边界

当前本地 COCO8 cache 与仓库 builtin/dev8 的8张图片逐图hash一致；资源manifest总体指纹44d258…已核验。控制实验默认split=val，实际消费4张，而manifest imageCount=8是整个资源包数量，两者不能混为一谈。

四张输入（000000000061 / 036 / 049 / 042）的顺序、shape `[1,3,640,640]`、float32 tensor SHA 在旧版、失败新版、保活新版间完全相同；可排除该控制实验的校准输入差异。未追溯历史生产实际消费张量，不把当前校准结果当生产历史证明。COCO8不是本业务精度验收数据集；本次未做标注集mAP / 漏检率评估。

当前PKX110已连接本地服务并换装正常产物，旧异常目录不存在。本轮前段仅只读包/目录/Manifest，未安装APK、清数据、改参数或手机推理；本次桌面文件补齐了旧异常模型bytes，不伪称当前手机取得的生产模型。

现有验证链主要是hash/shape/dtype/零图finite检查，异常产物可通过这些检查。新工具仅是离线诊断回归，**没有接入生产精度门禁**；没有改类别开关、签名、授权、撤权、隔离或M160语义。

初始两个isolated export尝试虽然设置YOLO_OFFLINE，第三方dataset校验仍触发外部Arial字体下载（日志保留）；后续显式阻断socket connect并跳过与校准像素无关的字体检查。没有访问生产服务；失败/成功审计及保活关键实验均在此防护后执行。网络阻断为本Python进程防护，不冒充OS级隔离。
