## 交付范围

- `/admin-next/models` 已由迁移占位页切换为 Vue 模型资产工作台，保留 `catalog`、`upload`、`calibration` 三个可深链页签。
- 模型目录读取真实 `/models` 投影，展示版本、生命周期、服务端绑定、移动端转换、签名和发布门禁；流绑定只列出 `serverBindable=true` 的模型。
- 版本详情读取真实版本 API，支持真实产物下载；激活仅改变新流默认模型；卸载使用版本级接口并保留服务端占用拒绝结果。
- 参数档案覆盖 Android/服务端平台、识别阈值、类别业务名称与编码、拍照/相机告警参数、审计、修订冲突和恢复默认确认。
- PT 与校准集 ZIP 使用原始字节上传和真实 XHR 进度；成功后清理文件与自动名称，失败或中断时保留表单，离页主动中止传输。
- 转换配置覆盖 local、WSL、remote；远程凭据只填写环境变量名。任务展示排队、运行、阶段、真实或不确定进度、耗时、日志、重试和按校准版本转换。
- 校准集支持列表、详情、内容哈希、上传和删除确认；内置或被模型/任务引用的版本由 UI/服务端共同保护。

## 风险边界

- 页面不根据文件名自行推断可用性，模型绑定、移动端就绪和发布资格均使用后端投影。
- 参数接口按模型 ID 对应当前模型版本，不支持写入任意历史版本；对话框同时显示所选资产版本与 API 档案版本。
- 上传完成只表示文件被服务端接收；模型须经 PT 验证、转换、签名和后端门禁后才显示相应就绪状态。
- 上传超时或客户端中止后的服务端事实可能不确定，页面提示用户刷新任务确认，不自动重发。
- 本任务没有修改转换器业务协议或生成新的模型权重；真实转换器与大文件处理能力继续由既有后端回归和部署配置承担。
