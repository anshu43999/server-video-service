# Built-in conversion smoke-test calibration set

This directory contains eight deterministic synthetic PNG images generated by
`tools/generate_builtin_calibration.py`. They are project-owned test fixtures,
not copies or derivatives of COCO/COCO8 images.

The legacy public dataset ID remains `coco8-dev` for configuration
compatibility. This asset exists only to verify that a production converter can
complete an offline INT8 export. It is not representative calibration data and
must not be used to assess or release a business model. Business conversions
should select a versioned calibration set uploaded through the admin console.
