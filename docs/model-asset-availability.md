# 模型资产可用性与绑定门禁

M28-T13：在不改变视频流模型版本持久化契约的前提下，统一管理页和服务端的可用性判断。

- `serverReady`：当前主产物为 PT/ONNX，文件存在、声明大小（若有）及 SHA-256 匹配，非占位且未弃用、撤回或卸载。这是资产可用条件，不保证目标设备运行时已加载或业务精度合格。
- `serverBindable`：满足上述条件，且该版本正是现有按 `modelId` 绑定接口会解析到的版本。同一模型族只提供一个绑定选项，避免多个版本使用相同选项值。
- `androidConverted`：登记的转换完成状态和当前 TFLite 完整性均有效，不依赖服务端 PT 是否仍存在。
- `androidReady`：转换产物有效、登记签名状态为 signed、原安装就绪标记成立、Android 产物完整且生命周期允许。设备仍需下载、验签和预热；本接口不替代设备安装验证。
- 后端绑定解析拒绝 DEPRECATED、REVOKED、UNINSTALLED，即使整个模型族已没有已发布版本，也不能回退绑定到撤回版本。没有 SHA-256 的服务端模型同样拒绝绑定。
- 目录刷新失败时页面清空过期目录和绑定选项，显示同步失败，避免继续使用上一次成功请求的可用性信息。
- “新流默认”不表示所有正在运行的视频流都已切换；已有运行会话不因这次优化被主动中断或更换。
