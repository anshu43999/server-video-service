# 移动端告警来源快照（M29-T19）

类型：接口与实现说明。沿用项目告警接收、证据和处置权限；来源快照只说明历史事实，不授予模型运行或跨项目访问权限。

`POST /aiyoloapi/projects/{project_id}/alerts/mobile-ingest` 增加可选 `provenance`，旧信封继续接收。场景事件示例：

```json
{
  "kind": "SCENE",
  "scene": {"sceneId": "scene-02", "name": "场景02", "revision": 3},
  "plan": {"planId": "plan-1", "name": "联合相机方案"},
  "memberId": "helmet-member",
  "model": {"modelId": "uploaded-06abc", "name": "安全帽", "version": "2.0.0"}
}
```

独立模型使用 `kind: STANDALONE`，仅提供 `model`，禁止附带场景、方案或成员。所有名称在事件创建时冻结，不根据当前目录、当前选择或摘要反查补写。`scene-camera:<sha256>` 继续作为稳定来源身份，不改成可读长字符串。

- 名称最多256字符；版本128字符；场景/方案/成员ID128字符；模型ID256字符。场景修订必须为正整数，不允许额外字段或客户端项目声明。
- 项目始终来自鉴权上下文及路由。快照作为生产端提供的历史标签保存，不代表服务端重新认证该历史配置。
- v1 重放的来源快照和来源类型属于不可变身份；不同快照返回409，不覆盖已有事实、证据及人工处置。缺失旧快照不从当前配置补造。
- JSON事件 payload 保存快照，无服务端数据库结构迁移；公共列表、详情、通知、项目报表与误报导出保留来源。兼容 `model` 投影由快照产生。
- 后台来源列紧凑显示来源类型、场景和模型版本，详情补充方案及场景修订；独立模型明确无场景，旧记录显示未记录。
