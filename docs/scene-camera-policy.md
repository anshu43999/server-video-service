# M36-T27 移动相机方案运行策略

状态：实现与自动测试，待人工复测；未部署或修改 Default Project。

ScenePlan 新增 `cameraPolicy`，创建/编辑/读取/批准目录和 plan resolve 均传递同一份值；修改方案沿用 revision 增长、清除批准和旧运行授权失效规则。仅用于移动端本机相机，不改变图片识别或 PC 视频任务。

|字段|默认|范围与含义|
|---|---:|---|
|frameInterval|5|整数 1–120，每 N 个分析入口收到的帧选择一个，首帧参与；1 不主动跳帧|
|batchTimeoutMs|5000|整数 1000–10000，整批执行期限；已完成有效结果保留，未执行成员不冒充超时|
|resultMaxAgeMs|6000|整数 batchTimeoutMs–15000，从帧采集计时|
|overlayHoldMs|1500|整数 0–3000，从有效结果显示计时；0 不保留历史框|

这些是显式工程默认，不是设备实测性能保证。同步成员共同消费选中帧；抽帧不改变预览、不生成失败或告警恢复事件。服务端缺省字段规范化为上述默认，显式 null/布尔/小数/字符串/未知字段拒绝。旧记录空列采用相同默认，不自动批准或重写业务记录。

管理端在视频运行方案内展示设置并验证范围；修改后仍需有权限的负责人保存并批准。Android M153-T02 对目录与 resolve 配置进行一致性核验。

部署时需先按正式流程应用 Alembic `20261104_33`，再启动新后端并发布管理端/App。本任务只在临时 SQLite 中验证迁移，不对现有数据库运行迁移。
