## 管理入口与权限

| 页面 | 路由（相对 `/admin/`） | 授权 |
| --- | --- | --- |
| 平台项目 | `platform/projects` | 平台超级管理员 |
| 平台账号 | `platform/accounts` | 平台超级管理员 |
| 平台审计 | `platform/audit` | 平台超级管理员 |
| 项目成员 | `members?project={id}` | 当前项目 `project.members.manage` |
| 项目审计 | `project-audit?project={id}` | 当前项目 `project.audit.read` |

平台区域管理项目元数据和全局账号；从平台项目卡片点击进入成员/审计时，通过 T10 外壳显式进入对应项目。当前项目名、代码和身份持续可见，后端记录平台进入。项目负责人无法进入平台账号、项目目录或平台审计页面；直接请求受服务端同样限制。

平台角色决定能否管理全局资源；项目角色决定账号在某个项目内可以执行的操作。普通平台账号（项目成员/项目负责人使用）需要先建立项目成员关系，平台超级管理员（管理全平台）进入项目时也必须显式选择项目。

## 交付流程

1. 平台创建账号：普通平台账号（项目成员/项目负责人使用）为默认角色；初始密码只用于本次创建，不持久化在浏览器。提交后（包括失败）、关闭弹窗和离开页面时清空密码。可显式创建平台超级管理员（管理全平台），并有权限范围说明。
2. 平台创建项目：填写名称、唯一代码，并选择已启用的初始负责人。不会把平台超级管理员隐式加入项目。项目名/代码可编辑，项目 ID 不变。
3. 成员分配：平台超级管理员从未加入的启用账号中选择用户，可设置用户或负责人角色。项目负责人只输入由平台提供的已有账号 ID 添加普通用户，不能查询全平台账号目录。
4. 成员维护：普通成员可启停/移除；平台超级管理员可变更项目角色。负责人不能直接编辑或移除负责人。成员状态与平台账号状态分别显示。
5. 移交负责人：选择启用账号的有效现有成员，一次请求提交原负责人和接收人的两个版本号。服务器事务中提升接收人、降级原负责人；负责人只能移交自己，平台超级管理员可移交任意有效负责人。自身移交成功后立即复核权限，清空旧维护界面。
6. 生命周期：停用、归档、恢复均显示目标、当前版本、影响说明并要求确认。停用保留获准成员维护及审计；归档成员管理不可用，负责人/平台超级管理员仍可查询项目审计；恢复通过平台项目页完成。
7. 审计：平台账号操作/平台拒绝与项目操作分别查询，显示时间、操作者、角色、动作、目标、版本、结果、拒绝码和请求关联 ID。采用游标分页，不返回原始变更载荷、密码或凭据。

服务器最后有效负责人、最后有效平台超级管理员和禁用账号保护保持有效；前端不会绕过这些限制。首期不提供硬删除项目或删除账号。

## 平台路由与项目路径分离

前端项目 API 路径门禁不允许未进入项目时调用任意 `/projects/{id}`。为平台生命周期操作新增与原实现共用同一 handler 的别名：

```text
GET/POST /aiyoloapi/platform/projects
PATCH    /aiyoloapi/platform/projects/{projectId}
POST     /aiyoloapi/platform/projects/{projectId}/suspend|archive|restore
```

这些路由只接受 `platform.projects.manage`。旧路径保留兼容；成员与项目审计继续使用显式项目路径。没有扩大 ProjectScope 的例外，也没有为普通账号增加任何能力。

新增审计只读接口：

```text
GET /aiyoloapi/platform/audit
GET /aiyoloapi/projects/{projectId}/audit
```

分别要求 `platform.audit.read` / `project.audit.read`，返回 `{events, nextCursor}`。`limit` 默认 25、最大 100；游标含作用域、时间和审计 ID，跨作用域或非法游标返回 422。每次请求重新授权，不把游标当访问凭据。数据库过滤 projectId 后排序/限制行数；内存实现同样过滤，并包含平台进入事件。SQLite 时间比较做格式归一化，防止默认秒精度字符串与绑定 datetime 的小数精度差异导致重复翻页。分页不是冻结快照，新记录需刷新首屏查看。

## 并发、错误与切换

- 编辑、启停、移除、生命周期操作使用读取时的 `expectedRevision`；移交使用双方 revision，拒绝盲覆盖。
- 确认期间禁用重复提交及关闭。409、网络中断、超时、5xx 或无法解析响应后锁定再次提交，须关闭弹窗并成功刷新服务端状态再重新操作；不自动重放不确定写入。
- 非密码草稿在失败弹窗中保留供核对，取消后不发送请求；失败不会提示成功。服务端已确认写入但随后列表读取失败时明确显示列表错误，不推断写入未发生。
- 页面卸载取消读写请求；generation 和读取序号防止迟到结果恢复旧项目/旧账号数据。项目选择、失权与多标签页继续复用 T10 外壳。
- 在停用/归档状态，仅新建的受能力门禁保护的维护/审计页面可挂载；尚未改造的业务页继续暂停，不能借此开放巡检或配置写入。
