# 管理后台项目上下文与安全切换

> M33-T12 更新：下文记录 T10 交付时点。业务页现已完成 capability 与只读改造；停用/归档重新验证后可读取服务端允许的历史数据，实时链路仍受限制。当前行为以 `admin-project-business.md` 为准，替代下文“外壳暂停全部旧业务页”的阶段性限制。

适用任务：M33-T10；契约：`m33-v1`；验证日期：2026-10-12。

## 身份、项目与入口

- Cookie 会话只证明平台账号身份；`GET /aiyoloapi/auth/me` 提供 `accountId`、`platformRole` 和契约版本，不能用旧 `role=admin/operator` 推断项目权限。
- `GET /aiyoloapi/auth/projects` 返回可访问项目、项目角色、成员/项目 revision、生命周期与有效 capability。客户端校验结构和版本；不兼容时停止业务请求，不回退到全局接口。
- 普通成员只有一个可访问项目时自动进入；多个项目时明确选择。平台超级管理员即使只有一个项目也需明确进入，不隐式成为成员。
- 进入前重新核验身份与可访问项目，再请求 `GET /aiyoloapi/projects/{projectId}`；服务端据此执行项目鉴权，平台进入由服务端记录审计。
- 固定项目栏持续展示项目名、项目代码、项目角色。平台模型资产/系统诊断是独立平台区，不混入当前项目上下文；平台模型页不再加载全局视频流列表。

## 状态与深链

状态机使用 `idle/loading/choosing/empty/ready/unavailable/error`，平台管理区另有 `platformReady`。

| 场景 | 行为 |
| --- | --- |
| 无成员关系 | 显示无项目和联系管理员说明，不请求项目业务数据 |
| 多项目 | 显式选择后才能挂载业务页面 |
| 刷新或深链 | 从 URL 的单个非空 `project` 参数重新验证，不能凭 URL 获权 |
| 不可见/非法项目 | 显示不可访问，不猜测默认项目，不请求目标业务数据 |
| 权限/角色/revision/生命周期变化 | 清空当前项目和旧数据，要求重新选择 |
| 身份不确定、网络验证失败 | 清空项目数据，显示错误与重试入口 |
| 未登录或会话失效 | 终止旧上下文并回到登录页 |
| 停用/归档 | 当前外壳暂停旧业务页、实时连接与媒体，展示明确提示 |

项目选择保存在本标签页内存与本标签页 URL 中，不写入共享存储。刷新须重新验证；无项目选择时不复用上一次业务缓存。切换入口丢弃旧页面筛选/弹窗，深链初次选择则保留其合法目标和参数。

## 切换顺序与资源清理

1. 同步清空 `projectId`，增加 generation；停止已注册的请求、WebSocket、媒体与上传。
2. 清空项目 store、告警 Pinia 缓存及平台就绪标记，更新页面 epoch。
3. 等待 Vue 卸载旧页面，释放页面轮询、弹窗和证据 object URL。
4. 重新校验账号与项目协议，获取可访问项目；选定项目后执行项目进入鉴权。
5. 仅最新 generation 可以发布结果并挂载新项目页面。

REST、WebSocket、MJPEG 与业务查询使用显式 `/aiyoloapi/projects/{projectId}/...`。项目资源缺少上下文时直接拒绝；显式请求另一个项目也被拒绝。请求解析完 body 后再次核验 generation，即使传输忽略 abort，旧结果也不能回写新项目。已排队的 WebSocket 消息/重连定时器同样不能恢复旧连接。请求使用 `cache: no-store`。

取消请求不等于撤销已经提交的服务端操作，尤其是写入与上传；不自动重试不确定的操作，重新进入后核验实际服务端状态。服务端每次请求的权限检查仍是最终安全边界，前端菜单与状态不构成授权。

## 持续核验与多标签页

- 可见页面每 15 秒核验身份、项目与成员 revision/capability；focus/pageshow 和短暂页面恢复只做软核验，不重建当前页面。页面连续隐藏超过 5 分钟或离线时清空旧上下文；返回后重新验证权限。
- 401 经身份复核后处理；403/404/实时连接拒绝触发项目权限复核。缺少某张证据的 404 不能直接等同于成员撤销。
- 登录/退出用 `localStorage` 的 `aiyolo.session.changed` 随机 nonce 通知其他标签页立即清空并重新验证。不会存储账号资料、密码、Token、项目选择或业务数据。存储不可用时由焦点与服务器检查兜底。
- 标签页共享浏览器 Cookie，但不共享项目选择；会话变化不会让另一个标签页继续展示旧项目数据。身份请求带 generation，退出后到达的旧身份结果不能恢复本地登录状态。
- 对仅发生在服务端、且没有触发客户端事件的权限修改，前端展示清理存在最多一个正常 15 秒核验周期及网络处理时间；不能宣称零延迟撤销。服务端已生效的请求级授权不依赖此定时器。
