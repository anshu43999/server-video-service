# 管理页模型市场与按流绑定（M09-T06）

`/admin` 的“模型资产”页由两个面板组成：市场目录和按流绑定。模型资产页面始终读取真实 `GET /api/models` 目录，不使用 `MOCK.models` 或静态模型卡片回退；全局 Demo 模式只保留给其他历史演示页面。场景下拉框只在浏览器内过滤已返回的公开字段（模型名称、版本、场景、用途、运行时和完整性状态）。

按流绑定面板读取 `GET /api/streams` 返回的 `model` 元数据，显示每路流当前模型及其场景/用途。选择新模型后，Live 模式调用 `PUT /api/streams/{stream_id}/model`，成功后更新该流的本地状态并重新渲染；刷新按钮可再次从取流侧读取绑定状态。演示模式只更新 Mock 状态，便于原型离线演示。

页面不渲染 `path`、`registry_path` 或任何令牌字段。服务端鉴权仍由 API 依赖执行，浏览器只处理安全的 JSON 投影；如部署启用令牌，应由反向代理或宿主应用注入请求凭据，不在页面中展示。
