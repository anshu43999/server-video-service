# M36-T07 为已登记 PC 模型补充运行验证与发布入口

## 完成摘要

为已登记 PC PT 模型增加受权限保护的 runtime load/warmup 验证 API，按当前模型哈希持久化验证结果并在模型资产页提供验证入口和状态展示；发布门禁拒绝未验证或哈希已过期的验证记录。

## 完成标准

平台管理员可对已登记的 PC 模型版本主动执行实际服务端 runtime load/warmup 验证，结果以验证状态和必要摘要持久化到模型版本；模型资产页可显示验证状态并触发验证，失败可查看安全的错误原因并重试；PC 发布仅在该模型版本与当前产物哈希相同的 runtime 验证通过时可提交，mobile-only 发布路径不受影响；覆盖 API 鉴权、模型不存在/非 PC/缺失/哈希变化/加载失败/成功验证/重试、版本隔离和并发发布门禁，服务端与管理端测试及构建通过。
