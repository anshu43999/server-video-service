# M33-T04 实现项目、账号与成员全生命周期 API

## 完成摘要

实现项目、平台账号与项目成员全生命周期 API；支持显式负责人、停用/归档/恢复、成员增删改与原子负责人移交、可访问项目及能力列表；加入账号 revision、平台审计、成功/拒绝/no-op 审计、最后负责人和最后平台管理员保护，以及数据库/内存一致的乐观并发语义。

## 完成标准

提供项目创建、查询、修改、停用、归档、恢复，以及账号创建、启停、项目成员增删、角色变更、负责人移交和可访问项目列表 API；禁止最后一个负责人被移除、项目角色越权提升和禁用账号继续访问；所有写操作记录操作者、项目、前后值、请求关联标识和时间，重复请求与并发修订有确定语义。
