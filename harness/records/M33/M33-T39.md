# M33-T39 将项目场景成员约束到项目模型清单

## 完成摘要

场景成员现仅接受当前项目已启用的 projectModelId，由服务端解析精确模型版本、目标端和冻结参数快照；拒绝未分配、跨项目、停用、重复及参数 revision 失配，允许同一项目模型被多个场景复用。项目模型参数更新后必须显式重新确认场景成员再审批；项目模型物理删除受场景引用约束。移除 legacyAssignment/旧全局目录授权路径，测试阶段迁移直接丢弃旧场景数据，并补齐 API 文档。

## 完成标准

场景及方案成员以当前项目已分配的精确模型版本/目标端为来源；拒绝未分配、已停用、目标端不匹配或跨项目的成员，允许同一已分配模型被多个场景复用。场景成员、方案参数快照、revision、审批与撤权校验保持事务一致；模型分配本身不创建/修改场景。移除依赖全局模型目录直接加入场景的旧授权路径及legacyAssignment只读投影，不迁移旧数据；隔离SQLite/PostgreSQL覆盖授权、复用、并发和撤权。
