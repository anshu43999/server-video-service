# M39-T01 实现并验收场景套件多成员运行授权

## 完成摘要

实现场景套件完整有序多成员短期运行授权、一次性轮换、防重放及权限修订绑定，完成旧库迁移和 Android 接入契约金样

## 完成标准

定义并实现多成员场景方案的在线短期运行授权与生命周期，授权完整绑定账号、项目、场景/方案修订、输入、移动端目标，以及完整成员集合中每个 memberId、精确 model version、artifact SHA-256 和批准参数摘要；签发及续期逐项校验项目权限、场景审批、当前修订、模型发布/撤回状态和客户端执行能力。采用复合 grant 或具备同等保证的逐成员 grant，但联合方案必须全有或全无；部分成员未授权、成员集合顺序/内容变化、旧revision、重放、跨项目/账号/方案/输入均拒绝。撤权、任一成员/模型/参数/审批变化、账号禁用或产物摘要变化后，运行中的授权失效且不能续期；开始/心跳/停止接口保持幂等并提供最小审计。单成员 M36-T19 契约兼容；只提供授权，不实现服务端推理调度，不改 Default Project 或生产。更新版本化API契约、金样与迁移（如需要），通过单元/API/隔离PostgreSQL并发、部分拒绝、重放及撤权/修订竞态回归，Harness校验通过；完成记录提供 Android M108-T04/T05 接入证据。
